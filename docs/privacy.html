Informativa sulla privacy

Sync Spotify-YTMusic è un'applicazione a uso esclusivamente personale del suo proprietario.

  • Accede all'account YouTube Music del proprietario solo per leggere e modificare le sue playlist.
  • I token di accesso e i dati delle playlist restano esclusivamente sul computer del proprietario.
  • Nessun dato viene venduto, condiviso con terzi o usato per pubblicità.
  • L'accesso può essere revocato in qualsiasi momento da myaccount.google.com/permissions.

L'uso dei dati ottenuti dalle API di Google rispetta le Google API Services User Data Policy.
